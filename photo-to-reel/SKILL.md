# 写真からリール（photo-to-reel）

写真を1枚もらって、**主役が動く**リール動画を作るスキルです。
ズームや切り替えだけのスライドショーではなく、写真の中の主役（ペット・キャラ・野菜・手作りのものなど）を動かします。個人の SNS 投稿向けです。

- 質問はすべて**番号で選べる形**にする。迷った人は「おまかせ」で既定値に進める
- **投稿はしない**。ユーザーが中身を見て「投稿して」と言ったときだけ投稿する

## 前提

- 動画の生成：あなた（Muse）の動画生成。1本10秒で、音（環境音や曲）も一緒にできる
- 画像の生成・編集：あなたの画像生成（画風を変える・描き足すときだけ使う）
- 作業環境の `python3`（3.9以上）と `ffmpeg` / `ffprobe`。仕上げは同じフォルダの `scripts/reel_tools.py` で行う
- あれば使う：Suno のコネクター（BGM を作る）、Instagram のコネクター（投稿する）、Google Drive（納品先）
- **始める前に、つながっているコネクターを確かめる**（ユーザーには聞かず、自分の使える道具の一覧で確かめる）
  - Suno：曲を作る道具（`audio-create` など）が使えるか → 使えなければ「Suno なし」で進める
  - Instagram：投稿の道具（`post-feed` など）が使えるか → 使えなければ「投稿なし」で進める
  - 確かめた結果は覚えておき、手順5と手順15で使う
- 動画1本で週の利用枠を約2ポイント使う。3カットなら約6ポイント。作る前に必ず伝える

以下、`reel_tools.py` は `python3 <このフォルダ>/scripts/reel_tools.py` のこと。どのコマンドも結果を JSON で返す。

## 流れ

### 1. 写真を受け取る

- 何が写っているかを一言でまとめて伝える：**主役・背景・主役の今の姿勢**（例：「段ボール箱の中で寝転んでいるキジ白の猫です」）
- 写真の縦横比を測って伝える：`reel_tools.py info 写真`（静止画にも使える。`near_ratio` と `orientation` を見て「横長 4:3 の写真です」のように伝える）
- 人の顔が写っている写真は、本人の許可があるものだけにしてもらう。他人の顔・有名なキャラクター・他社のブランドは使わない
- **写真が2枚以上来たら**：「このスキルは写真1枚から作ります。どれを使いますか？」と番号で聞く。何枚かをつないだ動画（店内ツアーなど）はこのスキルの対象外と伝える
- **動く主役がいない写真**（部屋・建物・風景だけ）のとき：主役が動くのがこのスキルの持ち味なので、そう伝えて番号で聞く
  ```
  この写真には動く主役がいないので、動きが小さい動画になりやすいです。どうしますか？
  1. 動かすものを決める（湯気・カーテン・木の葉・水面・光など）
  2. 別の写真にする
  3. このまま作る
  ```
- **お店・商品の宣伝に使いたい**と言われたら：このスキルは個人の投稿向けで、店名や営業時間などの文字は入れられないことを伝える。それでよければ進める

### 2. 作る比率を聞く

```
どの形で作りますか？
1. 縦長 9:16（リールの標準・おすすめ）
2. 元の写真の比率のまま
3. 横長 16:9
```

写真と違う比率を選んだら、合わせ方も聞く。

```
写真と形が違うので、合わせ方を選んでください。
1. 切り抜く（中身は元のまま。端が切れます）
2. 描き足す（足りない部分を描き足します。元にないものが増えます）
```

- **比率は、動画の指示では守られない**。動画の生成は、渡した画像の比率に引っぱられる（横長の写真を渡して「縦長 9:16」と書いても、横長で出た実例がある）。だから、**比率を変えるときは、必ず先にその比率の静止画を作ってから**動画に渡す
- 切り抜く：`reel_tools.py crop 写真 out.png --ratio 9:16`（主役が中央にないときは `--x 0.3` のように中心をずらす）。切り抜いた画像を見せて、主役が切れていないか確かめてもらう
- 描き足す：画像の生成で「構図と主役はそのままで、上下（左右）だけを自然に描き足して 9:16 にする」と頼む。できた画像を見せて確かめてもらう

### 3. 写真をどうするか聞く

```
写真はどうしますか？
1. そのまま（写真の見た目のまま動かす）
2. イラスト調
3. 手描きアニメ映画風
4. 3Dアニメ映画風
5. 自分で書く
```

- 2〜4 は、画像の段階で画風を変えてから動画にする。**静止画を作らずに動画の指示だけで画風を変えない**（画風が付かなかったり、構図が作り直されたりする）
- 画風を変える指示には、必ず次を入れる：
  `構図・主役の位置・背景の配置は元の写真のまま変えず、画風だけを変える。画面に文字は入れない。（選んだ比率）。`
- 各画風の書き方：
  - イラスト調：`はっきりした線と、平たい塗りのイラスト`
  - 手描きアニメ映画風：`水彩で描いたような背景、やわらかい自然光、温かみのある色`
  - 3Dアニメ映画風：`丸みのある立体の質感、つやのある表面、明るい照明`
- 選ぶ前に、事実として次を伝える（どれがよいかは勧めない。好みで選んでもらう）：
  - 画風を変えると、細部は描き直される。顔つき・模様・体形が変わることがある
  - 写っている文字（ラベル・店名・ロゴ）は消えることが多い
  - 横長の写真を縦長にするときは、上下に元にないもの（床・空など）が描き足される
- **加工は、画風が決まったらすぐ（手順4に進む前に）行う**。比率を変える必要があるときも、ここで一緒に作る
- 加工した画像を見せて「これで動画にしてよいか」を聞く。気に入らなければ作り直す。OK が出てから手順4へ進む
- 「そのまま」で比率も写真と同じなら、写真をそのまま動画の最初のコマにする
- 「会社名・作品名＋風」（〇〇風）は選択肢に出さない。ユーザーが自分で書いた場合は、その言葉で試してよい

### 4. 長さを聞く

```
長さはどうしますか？
1. 10秒・曲つき（1本で作ります。曲も動画と一緒にできます。枠は約2ポイント）※迷ったらこれ
2. 15〜20秒・3カット（「伸び→あくび→座り直し」のように、動きが3つに分かれるとき向け。枠は約6ポイント）
```

- 見せたい動きが1つなら 1、3つに分かれる話なら 2、と一言添えてよい。どちらが向くかは勧めず、この目安だけ伝える

- **10秒**：動画の生成で曲も一緒に作る。曲の雰囲気は次の5で聞く
- **3カット**：1本10秒で3本作るが、**どのカットも動いている所だけを使い**、つないで15〜20秒にする。動画は10秒より早く動き終わり、残りは止まったままになりやすいため（手順10・12）
- **3カット**：動画の生成では曲を入れない。3本に別々に曲を入れると、つなぎ目で同じ曲が一度消えて頭から鳴り直してしまうため。BGM は次の5で決める

### 5. 曲・BGM を聞く

**10秒を選んだとき**：曲の雰囲気を聞く。

```
曲の雰囲気はどうしますか？
1. 明るい（ウクレレと鉄琴）
2. のんびり（アコースティックギターとやさしいピアノ）
3. わくわく（手拍子と軽快なギター）
4. 自分で書く
5. 曲なし（環境音だけ。投稿するときに Instagram で曲を選べます）
```

- 選んだ雰囲気を、プロンプトの音の行（下の「プロンプトの書き方」）の（雰囲気）に入れる。例：1 なら `明るいウクレレと鉄琴のインスト曲`
- 5 を選んだら、音の行は `音は環境音だけで、音楽は入れない。` にし、納品のときに下の「Instagram で曲を選ぶ人への案内」を伝える

**3カットを選んだとき**：BGM の付け方を聞く。どの場合も、動画の環境音は残す。

Suno のコネクターが**つながっているとき**：

```
BGM はどう付けますか？ 動画には環境音を残します。迷ったら 1 を選んでください。
1. Instagram で投稿するときに曲を選ぶ（完成した動画には BGM を入れません）
2. Suno で曲を作って動画に入れる（利用枠と、曲の使い方の条件を確かめます）
3. 使ってよい音源を動画に入れる（自分で作った曲など。ファイルを渡してください）
```

Suno のコネクターが**つながっていないとき**（Suno の選択肢は出さず、番号を詰める）：

```
BGM はどう付けますか？ 動画には環境音を残します。迷ったら 1 を選んでください。
1. Instagram で投稿するときに曲を選ぶ（完成した動画には BGM を入れません）
2. 使ってよい音源を動画に入れる（自分で作った曲など。ファイルを渡してください）
```

- つながっていないのにユーザーが「Suno で作って」と言ったら、つながっていないことを伝え、Muse のコネクターの設定で Suno をつなげば使えると案内する。**つながっていないまま Suno の道具を呼ぼうとしたり、別の方法で曲を作ろうとしたりしない**

**Instagram で曲を選ぶ人への案内**（3カットの 1、10秒の「曲なし」を選んだ人に、納品のときに伝える）

```
投稿するとき、Instagram アプリで曲を選べます。動画の音（環境音）も残ります。
曲を選んだら音符マークをもう一度押し、「管理」で「カメラ音声」と「音楽」の大きさを調整して、プレビューで聞いてから投稿してください（投稿した後は音量を変えられません）。
Instagram の曲は個人の非商用の利用が前提です。お店や商品の宣伝に使うときや、ビジネスアカウントでは、選べる曲が限られることがあります。
```

- 「曲を付けると届きやすい」など、効果をうたう言い方はしない

**Suno を選んだとき**

- 作る前に、何に使うか（個人で楽しむ投稿か、宣伝・収益化を伴うか）を聞き、Suno のプランで今回の使い方ができるか、ダウンロードできるかをユーザーに確かめてもらう。細かい条件はスキルの中で断定せず、Suno の規約を見るよう伝える
- 雰囲気を番号で聞く（1. 明るい　2. のんびり　3. わくわく　4. 自分で書く）。インスト（歌なし）・30秒で1回作る。**1回で2曲でき、クレジットを使う**ので、作る前に確かめる。ダウンロードにも別の枠を使うことがあるので、それも確かめる。2曲のうち、雰囲気に合う方を使う
  - 例：`audio-create` に `instrumental: true`、`duration: 30`、style は `cheerful acoustic ukulele, light glockenspiel, soft hand claps, playful, bright and warm, simple loopable, no vocals` のように楽器と雰囲気を英語で

**使ってよい音源を選んだとき**

- 自分で作った曲か、動画に入れて Instagram に投稿してよいと分かっている音源だけにしてもらう。**買っただけの曲・配信サービスから保存した曲・テレビや動画から録った音は使えない**と伝える
- どこで手に入れた音源か分からないときは、使わずに 1（Instagram で曲を選ぶ）をすすめる

### 6. 用途を聞く

```
どんな投稿にしますか？
1. ペット
2. 家族・子どもの作品
3. 家庭菜園・料理・手作りのもの
4. キャラクター・イラスト
5. そのほか
```

- キャプションの言葉づかいとハッシュタグを決めるのに使う

### 7. 構成案を出す

番号で3案と「自分で書く」を出す。どの案も、**主役の今の姿勢から始まる動き**にする。

- 10秒：0〜2秒＝つかみ／2〜7秒＝見せ場／7〜10秒＝締め（最初のコマに近い姿勢で止まる）
- 3カット：カット1＝つかみ／カット2＝見せ場／カット3＝締め（手を振る・決めポーズ など）
- 3案は、下の「伸びやすくする工夫」に沿って作る

構成が決まったら、出だしの見せ方を聞く。

```
出だしはどうしますか？
1. 元の写真を一瞬見せてから動き出す（「写真が動き出した」と分かる見せ方）
2. いきなり動画から始める
```

- 1 は仕上げで `intro` を使う（手順12）。最初の0.8秒は元の写真のまま止まり、0.3秒で動画へ溶ける
- 画風を変えたときは、1 にすると「元の写真 → 加工した絵が動く」の変化そのものが見どころになる
- 比率を「描き足す」で変えたときは、元の写真と加工した絵で写る範囲が違うので、溶けるところで絵が大きく変わる

### 8. カメラを聞く

```
カメラはどうしますか？
1. 固定（おすすめ・迷ったらこれ）
2. 締めだけゆっくり寄る
```

- 「締め」とは、10秒なら最後の3秒（7〜10秒）、3カットならカット3のこと
- 10秒で「寄る」を選んだ人には、事実として伝える：寄りが「ゆっくり」にならず、終わりで急にアップに切り替わったことがある。その場合、繰り返し再生で最初の全身の絵に戻るところで、大きさの違う主役が重なって見える

### 9. 確認

組み立てたプロンプト（3カットなら3本分）を見せ、使う枠（約2／約6ポイント）を伝えて「作ってよいか」を聞く。

### 10. 生成

プロンプトの組み立ては下の「プロンプトの書き方」に従う。

- 10秒：加工した画像（またはそのままの写真）を最初のコマにして1本作る。当たり外れがあるので、ユーザーが望めば2本作って良い方を選んでもらう（枠は2本分）
- 3カット：順番に作る
  1. カット1：最初のコマ＝加工した画像（またはそのままの写真）
  2. カット1の `sheet` を作って見て、**使う秒**を決める（下の目安）。その位置のコマを切り出す：`reel_tools.py frame cut1.mp4 last1.png --at 使う秒`
  3. カット2：最初のコマ＝`last1.png`
  4. 同じようにカット2の使う秒を決めてコマを切り出し、カット3を作る。カット3も使う秒を決める
  5. 決めた3つの秒は手順12の `--trims` で使うので、覚えておく

  **使う秒の目安**（合計 15〜20秒）

  | カット | 使う秒 | 決め方 |
  |---|---|---|
  | カット1（つかみ） | 3〜5秒 | つかみの動きが終わったところ |
  | カット2（見せ場） | 4〜7秒 | 見せ場の動きが終わったところ。その後に主役が顔を伏せる・後ろを向くなど、見せたくない動きが続いていたら、その手前 |
  | カット3（締め） | 4〜7秒 | 締めの姿勢で止まってから約1秒。それ以上止まった絵を続けない |

  - コマを並べた画像で、**隣のコマと主役の姿勢が変わらなくなった最初の秒**を「動きが終わったところ」とする
  - 決めた秒は、並べた画像と一緒にユーザーに見せる（例：「カット2は6秒まで使います。7秒からは2匹とも顔を伏せるので外します」）

### 11. 検品

あなたは動画を再生して見られないので、コマを並べた静止画と数値で確かめる。

1. `reel_tools.py sheet 動画 sheet.jpg`（1秒ごとのコマを横10枚で並べる）を作って見る
2. 3カットのつなぎ目：前のカットで切り出したコマと、次のカットの最初のコマを `reel_tools.py ssim A.png B.png` で比べる
3. 結果をユーザーに伝え、**並べた画像も一緒に見せる**。下の表で「不合格」が1つでもあれば、そう伝えて作り直すか聞く（黙って仕上げに進まない）。「要相談」は、ずれを具体的に伝えて、進むか作り直すかをユーザーに選んでもらう。作り直すと枠をもう1本分使うことも伝える

| 見るところ | 合格 | 不合格 |
|---|---|---|
| カメラ（「固定」を選んだとき） | 背景（山・建物・柵・家具など）の位置と大きさが全コマで同じ | 途中で背景がずれる・大きくなる |
| カメラ（「締めだけ寄る」を選んだとき） | 締めの前までは背景が同じ。締めで1秒ごとに少しずつ大きくなる | 締めの前から動く／1秒の間に主役が急に大きくなる（アップへの切り替わり） |
| 場面 | 最後まで同じ場所 | 途中で別の場所・別の構図に変わる |
| 主役 | 最初のコマと同じ主役に見える | 別の生き物・別の物に変わる、増える、消える |
| 顔・手足 | 崩れていない | 目・口・手足・指が崩れている、数が変わる |
| つなぎ目（3カット） | SSIM 0.95 以上 | 0.90 未満（0.90〜0.95 は目で見て決める） |

| 要相談（ユーザーが決める） | 例 |
|---|---|
| 動きが指示と違う | 「その場で跳ねる」が「手前へ飛び出す」になった／しっぽを振る動きがコマでは見えない |
| つかみが弱い | 最初の2秒の動きが小さい |
| 締めが最初の姿勢に戻らない | 10秒で、最後の姿勢が最初と大きく違う（繰り返し再生で溶かす部分が目立つ） |
| 使える秒が短すぎる（3カット） | 動きがすぐ終わり、目安の秒に届かない（合計が15秒を大きく下回る） |

### 12. 仕上げ

比率に合わせて大きさを決める（9:16 なら 1080×1920、16:9 なら 1920×1080、それ以外は長い辺を 1920）。`--ratio` に選んだ比率を渡す。

**10秒**

```
reel_tools.py concat step1.mp4 cut1.mp4 --ratio 9:16       # 拡大
reel_tools.py intro step1.mp4 photo.png step1b.mp4          # （出だし 1 のときだけ）元の写真を頭に足す
reel_tools.py loopfade step1b.mp4 step2.mp4                 # 最後の0.5秒で最初のコマへ溶かす
reel_tools.py loudness step2.mp4 final.mp4                  # -14 LUFS に揃える
```

- 出だし 2 のときは `intro` を飛ばし、`loopfade step1.mp4 step2.mp4` にする
- `intro` に渡す写真は、比率を合わせた元の写真（手順2で切り抜いた画像。比率が同じなら元の写真そのまま）。写真は動画の大きさに合わせて自動で切り抜かれる
- `intro` の後に `loopfade` をかけると、最後は元の写真へ溶けて戻る（繰り返し再生で「写真 → 動く → 写真」になる）

- `loopfade` を入れる理由：リールは繰り返し再生される。10秒版は最後のコマが最初の姿勢に戻らないので、そのままだと戻るところで絵が飛ぶ。溶かしている0.5秒は主役が二重に透けて見えるが、再生するとふわっと切り替わる程度

**3カット**

```
reel_tools.py concat step1.mp4 cut1.mp4 cut2.mp4 cut3.mp4 --ratio 9:16 --trims 4,6,5
                                                            # つなぐ＋拡大（--trims は手順10で決めた、各カットの使う秒）
reel_tools.py intro step1.mp4 photo.png step1b.mp4          # （出だし 1 のときだけ）以下は step1b.mp4 を使う
```

続けて BGM の選択に応じて：

- BGM なし：`reel_tools.py loudness step1.mp4 final.mp4`
- Suno／手持ちの音源：`reel_tools.py bgm step1.mp4 bgm.mp3 final.mp4`
  - 環境音を -20 LUFS に持ち上げ、BGM をその **9 dB 下**で**混ぜる**（差し替えない）。最後に全体を -14 LUFS に揃える
  - ユーザーが「BGM をもっと大きく」と言ったら `--below 6`、「小さく」なら `--below 12`
  - 環境音に変な音（人の声・電子音など）が混じっていると言われたら、`reel_tools.py bgmonly step1.mp4 bgm.mp3 final.mp4`（環境音を使わず BGM だけ）

- 音量の仕上げは必須。生成したままの音は -30〜-40 LUFS とかなり小さく、リールで流れるとほぼ無音に聞こえる
- できたら `reel_tools.py info final.mp4` で大きさ・長さ・ラウドネスを確かめる。**-14 ± 1 LUFS（-15〜-13）なら合格**。外れたら `loudness` をもう一度かける

### 13. キャプションとカバー画像

- キャプション：最初の1行は続きを読みたくなる一文（動画の見どころを先に言う。例：「最後の座り直しまで見てほしい」）。本文は2〜4行。ハッシュタグは3〜5個（多すぎない）
- 最後に、見た人が返しやすい問いかけを1つ入れてもよい（例：「うちの子は何秒で跳ねたでしょう？」）
- 場所・名前など、ユーザーに聞いていない事実は書かない
- **ユーザーの気持ちや思い出を作らない**（「ここがお気に入りです」「びっくりしました」など）。書きたいときは、ユーザーに一言聞くか、`（ここに一言）` のように空けておく
- 動画の中で起きたことを書くときは、本当に写っていることだけにする
- カバー画像：締めの場面から1枚選ぶ（`reel_tools.py frame final.mp4 cover.png --at 秒`）。候補を2〜3枚見せて選んでもらってもよい

### 14. 納品

動画・カバー画像・キャプション（テキスト）を、ユーザーが指定した場所（Google Drive など）に置く。置き場所を聞いていなければ聞く。**ここで止める。投稿はしない。**

- ファイル名は `年月日_主役_reel.mp4`／`年月日_主役_cover.png`／`年月日_主役_caption.txt`（例：`20261115_猫_reel.mp4`）。同じ日に2本目を作ったら `_2` を付ける
- Drive へ上げるコマンドは、使っている Drive のコネクターの説明に従う。置いたら、フォルダの一覧でファイル名と大きさを照らし合わせる
- 動画に BGM を入れていない（3カットの「Instagram で曲を選ぶ」、10秒の「曲なし」）ときは、手順5の「Instagram で曲を選ぶ人への案内」をここで伝える

### 15. 投稿（「投稿して」と言われたときだけ）

- Instagram のコネクターがつながっていないときは、投稿はできないことを伝え、納品したファイルを Instagram アプリから投稿するよう案内する（カバー画像の選び方・キャプションの貼り付け・AI ラベルの付け方も添える）

- Instagram のコネクターでリールとして投稿する（動画1本を渡すとリールになる。カバー画像が必要。キャプションは 2,200字以内、動画は 100MB 以下）
- **投稿先のアカウントを毎回はっきり聞く**。つながっているアカウントが複数あることが多い。前回と同じでも省略しない
- 投稿の前に、アカウント名・動画・カバー画像・キャプションを並べて見せ、「投稿してよいか」をもう一度聞く
- 9:16 以外で作った動画は、リールの画面では余白が出たり端が切れたりすることを伝える
- 時間を決めて出したい人には予約投稿を案内する
- 投稿できたら、投稿の URL を伝え、続けて AI ラベルの付け方を案内する（下の「動画に入れないもの」）

## プロンプトの書き方

### 必ず入れる文（カメラ固定）

```
カメラは三脚に固定。最初から最後まで、ズーム・寄り・引き・パン・揺れは一切なし。
カットは切り替えず1カットのまま。画面の中で動くのは主役だけ。
画風・色・背景は最初のコマのまま変えない。画面に文字を出さない。
```

これを入れないと、カメラが大きく動いたり、途中で場面が切り替わったりする。

カメラで「締めだけゆっくり寄る」を選んだときは、**1行目の全体**（「カメラは三脚に固定。最初から最後まで、ズーム・寄り・引き・パン・揺れは一切なし。」）を次に差し替える。2行目・3行目はそのまま。

- 10秒：`カメラは三脚に固定。0〜7秒はズーム・寄り・引き・パン・揺れは一切なし。7〜10秒の3秒間だけ、一定の速さでゆっくり少しだけ寄る（急にアップにしない）。`
- 3カット：カット1・2は1行目のまま。カット3だけ `カメラは三脚に固定し、10秒かけて一定の速さでゆっくり少しだけ寄る（急にアップにしない）。`

### 音の行（上の文の後ろに付ける）

- 10秒：`音楽：（雰囲気）のインスト曲、テンポはゆったり一定、歌なし。環境音は小さく。`
- 3カット：`音は環境音だけで、音楽は入れない。`

「曲を最後まで同じ大きさで鳴らす」のような、曲の終わり方の指示は効かない（逆に終わりが小さくなった例がある）。書かない。

### 動きの書き方

- **時間で区切って**書く（`0〜2秒：〜。2〜7秒：〜。7〜10秒：〜。`）
- 「動かして」のようなあいまいな言葉だけで終わらせない。何がどう動くかを書く
- **動きは、最初のコマの主役の状態から始める**。立っている主役に「土から飛び出す」と書くと、いったん沈んでから出てくる逆の動きになる
- **0秒から動き始める**ように書く（「0秒で〜し始め、2秒までに〜」）。最初のコマのまま止まっている時間を作らない
- **つかみ（最初の2秒）は、はっきり大きな動き**にする（跳ねる・振り向く・両手を上げる・湯気がふわっと立つ・しっぽを大きく振る など）。控えめな動きを任せると、葉が揺れてまばたきするだけ、のように弱くなる
- 主役は**正面かこちら向き**を保つ。体ごと横や奥を向かせない（向いた瞬間に場面が変わりやすい）
- 守りたい小物は「最後まで見えるように」と書く

### 例（10秒・立っているキャラクター）

```
カメラは三脚に固定。最初から最後まで、ズーム・寄り・引き・パン・揺れは一切なし。
カットは切り替えず1カットのまま。画面の中で動くのは主役だけ。
画風・色・背景は最初のコマのまま変えない。画面に文字を出さない。
音楽：明るいウクレレと鉄琴のインスト曲、テンポはゆったり一定、歌なし。環境音は小さく。
0〜2秒：大根のキャラクターが、その場でぴょんと大きく跳ねる。
2〜7秒：こちらへちょこちょこ3歩歩いてきて、葉っぱがふわふわ揺れる。
7〜10秒：立ち止まり、笑顔で両手を振って、正面を向いた立ち姿で止まる。
縦長9:16、10秒。
```

## 伸びやすくする工夫（このスキルに組み込んであるもの）

リールは、最初の1〜2秒で見続けるかが決まり、最後まで見られて繰り返されるほど届きやすい、と言われる。数値で確かめたものではないが、次を手順に組み込んである。構成案を作るときも、この順で考える。

| 工夫 | どこでやるか |
|---|---|
| **0秒から動く**：最初の0.5秒を止めたままにしない | プロンプトの「0〜2秒」に、始まった瞬間の動きを書く（手順10） |
| **最初の2秒に大きな動き**（つかみ） | 構成案の 0〜2秒（手順7）・動きの書き方 |
| **「写真が動き出した」と分かる出だし** | 出だしの見せ方 1（手順7）→ `intro`（手順12） |
| **見どころを先に言う** | キャプションの最初の1行（手順13） |
| **短く、最後まで見られる長さ** | 10秒・1カット（手順4） |
| **締めで決める**：最後に正面・決めポーズ・最初に近い姿勢で止まる | 構成案の 7〜10秒（手順7） |
| **繰り返し再生がつながる** | `loopfade`（手順12） |
| **音が小さすぎない** | `loudness` で -14 LUFS（手順12） |

- 3案のうち1つは「意外な動き」（ペットが手を振る・野菜が歩く・絵の中の人がこちらを向く など）にする。写真の主役がしないはずの動きは、それだけで目を止める
- 入れていないもの：画面の文字（テロップ）・流行りの音源。文字は個人の投稿では無くても成り立つので入れない。流行りの音源は、投稿するときに Instagram で選べることを納品のときに伝える（手順5の案内）

## 動画に入れないもの

- 「AI生成」などの文字・透かし・ロゴ・テロップは動画の中に入れない
- AI で作ったことの申告は、Instagram の AI ラベルで行う
  - **Instagram のコネクターの投稿機能（post-feed）では AI ラベルを付けられない**（2026-11-15 実測）
  - 投稿したら、必ず次を案内する：「Instagram アプリでこのリールを開き、右下の「…」→「情報を編集」→「AIラベルを追加する」をオンにして、右上のチェックで保存してください」

## 知っておくこと（実測）

- 動画は1本10秒。縦長だと 704×1248 前後・24fps。音は 24kHz モノラル
- 最初のコマは渡した画像そのものではなく、描き直される（構図・主役・背景は合う）
- 前のカットの最後のコマから次のカットを作ると、つなぎ目は目で見て分からないくらいにつながる
- 10秒の動画は、指示した動きを10秒より早く終えて、後ろは止まったままになりやすい。3カットを全部つないだ25秒の版では、最後の約8秒がほぼ止まった絵と小さな音になり、後ろを切った18秒の版のほうが良いと判断された（2026-11-15）
- 1回ごとに当たり外れがある。指示した動きと違う動きになることもある
- あなた自身に、単体の音楽（BGM）を作る機能はない。曲が要るときは、動画の生成で一緒に作る（10秒）か、Suno か、手持ちの音源
